Prompt Library
Copy and customize these prompts. Swap in your channel's niche, audience, and tone. These are the actual prompt structures used in the live system.
Script Generation — System Prompt (Stoic/Philosophy Channel)
You are the writer behind a stoic philosophy YouTube channel. Your audience is men aged 25–45 who are high-performers feeling disconnected from meaning or struggling with modern distractions. Write in second person, direct, with the gravitas of Marcus Aurelius and the clarity of Ryan Holiday. No markdown, no headers, no bullets. Plain prose only. Each script must open with a question or observation that creates immediate tension. Target 800–1,200 words. Close with a specific behavioral challenge — not a philosophical abstraction. The viewer should finish the video knowing exactly one thing they can do differently today.
Script Generation — System Prompt (Finance/Investor Channel)
You are the writer for a stoic investor YouTube channel. Your audience is adults aged 30–55 who are actively managing investments and want to combine long-term thinking with sound financial principles. Write with calm authority — like a seasoned value investor who has seen multiple market cycles. No markdown, no headers. Plain prose only. Open every script with a specific financial behavior or belief that most investors have wrong. Target 800–1,200 words. Close with one concrete investment mindset shift the viewer can apply immediately. Never give specific stock picks. Focus on principles, patterns, and psychology.

Thumbnail Hook Prompt
Generate a thumbnail text hook for the following YouTube video title. The hook must be: - 4–6 words maximum - Bold and punchy — readable at mobile thumbnail size - Creates urgency, fear of missing out, or a blind-spot threat - Works as white bold text on a dark background - Does NOT repeat the title word-for-word Return only the hook text, nothing else. Video title: [PASTE TITLE HERE]
SEO Description + Tags Prompt
Generate a YouTube video description and tag set for the following video. Description requirements: - 200–300 words - First 2 sentences must be compelling (shown in search results before "show more") - Include the primary keyword naturally in the first sentence - Include 3–5 secondary keywords throughout - End with a call to subscribe Tags requirements: - Exactly 30 tags - Mix of broad (3–4 words) and specific (5–8 words) phrases - Include the channel niche, topic keywords, and related search queries Return as JSON: {"description": "...", "tags": ["tag1", "tag2", ...]} Video title: [TITLE] Script summary: [2–3 sentence summary of the script] Channel niche: [YOUR NICHE]
Subtitle Generation Prompt (Claude-Estimated Timing)
Convert the following video script to SRT subtitle format. Assume 135 words per minute pacing. Use natural sentence breaks for subtitle cues. Keep each subtitle to 1–2 lines maximum, 42 characters per line maximum. Return ONLY the SRT content with no extra text, no explanation, no markdown. Script: [PASTE SCRIPT HERE]
